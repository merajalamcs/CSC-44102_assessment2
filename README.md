# Snake Game — CSC-44102 Assessment 2

## ✅ Overview
A simple Snake game built in Python using Tkinter for GUI, developed in small, logical commits to demonstrate Git workflow and software engineering practices.

## ▶ How to Run
```bash
python main.py
```
Ensure you have Python 3 installed. Tkinter is included by default on most systems. On Linux, install with:
```bash
sudo apt-get install python3-tk
```

## 🎮 Controls
- **Arrow Keys** → Move the snake
- **Space** → Pause / Resume
- **R** → Restart after game over

## ✨ Features
- Snake movement and growth when eating food
- Food spawning at random positions
- Score tracking in a status bar
- Wall collision and self-collision detection
- Game-over overlay with restart option
- Pause and resume functionality
- Speed-up every N foods for added challenge
